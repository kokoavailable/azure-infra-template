# stacks/AGENTS.md

## Scope

This directory contains stack templates and composition patterns.

## Rules

Templates must be generic.

Do not include real environment values.

Do not include real backend values.

Keep examples safe and fake.

A stack template should include:

- README.md
- versions.tf
- providers.tf
- backend.tf
- backend.hcl.example
- locals.tf
- variables.tf
- main.tf
- outputs.tf
- terraform.tfvars.example
